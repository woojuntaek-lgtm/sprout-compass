# 새순 나침반

달리는 힘은 이미 충분합니다 — 가끔은 방향을 확인할 시간. 에니어그램 3번(성취가) 이야기를 바탕으로, 누구나 1분 만에 나의 **속도·과속·방향**을 점검하고, 30초 게임으로 "무엇을 누를지 고르는 힘"을 겨루고, 과정을 칭찬하는 카드를 만드는 앱입니다. 「에니어그램 3번 성취가」 강의 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

> **바로 하기: https://woojuntaek-lgtm.github.io/sprout-compass/**

## 특징
- 🧭 계기판: 12문장 1~5점 → 속도(추진력)·과속(보여주기·일 중독)·방향(내면의 소리) 세 바늘과 상태(곧게 뻗는 새순 / 과속 주의 / 방향 점검 필요 / 천천히 자라는 나무 / 잠시 멈춘 엔진), 맞춤 처방
- 🎯 목표 탭탭: 30초 반응 게임 — 🎯 내 목표는 누르고, 📸 보여주기는 피하고, ☕ 쉼표는 챙기기. 점점 빨라짐, 최고 기록 저장
- 👏 과정 칭찬: 나에게 셀프 칭찬 / 3번에게 응원(과정 인정 + "마음은 어때요?") 카드 만들기 → 복사·공유
- 🌱 3번 한눈에: 한 줄 정의, 동양 수리(木·甲·동·녹색, 새순), 엔진과 질주, 날개, 스트레스·성장 방향, 건네는 말

성찰을 돕는 참고용이며 심리검사나 전문 상담을 대신하지 않습니다. 입력 내용은 기기 밖으로 나가지 않습니다.
